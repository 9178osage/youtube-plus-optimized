# 优化脚本

一组浏览器用户脚本。主脚本为 YouTube 增加播放器工具、标签页和界面设置。仓库还收录了适用于 YouTube、X 和部分文档网站的独立脚本，可按需安装。

## 脚本列表

| --- | --- | --- |
| [YouTube+ 优化版](./YouTube%2B%20%E4%BC%98%E5%8C%96%E7%89%88.user.js) | `3.0.1.3` | 增强 YouTube 播放器和视频页面，包含 YouTube Music 界面设置。 |
| [YouTube CPU Tamer（Safari 优化版）](./%E6%9C%AA%E5%91%BD%E5%90%8D1%20%E4%BC%98%E5%8C%96%E7%89%88.user.js) | `2026.11.08.1` | 调整 YouTube 的计时器调度，以减少播放时的浏览器开销。 |
| [更好的 X（BetterX）](./%E6%9C%AA%E5%91%BD%E5%90%8D2%20%E4%BC%98%E5%8C%96%E7%89%88.user.js) | `3.9.0.1` | 记录和搜索时间线帖子，支持关键词高亮、广告过滤和媒体下载。点击页面徽标或按 `Alt+X` 打开面板。 |

## 安装

1. 在浏览器中安装并启用用户脚本管理器，例如 Tampermonkey。
2. 从上表打开要安装的脚本，点击 **Raw**。如果管理器弹出安装页，确认安装。如果浏览器直接显示源码，在管理器中新建脚本，粘贴完整源码并保存。
3. 刷新对应网站。安装 YouTube+ 后，点击 YouTube 页面顶部的齿轮，或从脚本管理器菜单选择 **YouTube+ 设置**。

安装时使用 `.user.js` 文件。每个脚本另有一份同名 `.txt` 文本副本。

## YouTube+ 功能

- **播放器**支持调速、截图、画中画、A–B 循环，以及记住播放进度和手动选择的画质。
- **视频页面**可用标签页浏览简介、评论、推荐视频和播放列表，并提供评论翻译和播放列表搜索。
- **界面**提供主题、字幕样式和 YouTube Music 布局设置，可在设置中开关广告过滤。
- **下载**提供视频和音频下载入口。部分下载和翻译功能依赖外部服务，可用性取决于对应服务。

| 默认快捷键 | 操作 |
| --- | --- |
| `G` / `H` / `B` | 减速 / 加速 / 重置速度 |
| `Q` / `E` | 设置循环起点 / 终点 |
| `R` / `X` | 切换循环 / 清除循环点 |
